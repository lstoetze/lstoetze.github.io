3. Adding residence with Bayes’ rule

Steps: (1) \(P(\text{surname} \mid \text{race})\) from \(P(\text{race} \mid \text{surname})\); (2) attach the precinct’s race composition \(P(\text{race} \mid \text{residence})\); (3) \(P(\text{surname} \mid \text{residence})\) by summing over races; (4) \(P(\text{race} \mid \text{surname}, \text{residence})\). The code is long: read it, then run it.

Read this code (it is not run yet):

FLCensus <- read.csv("FLCensusVTD.csv")
race.prop <- apply(FLCensus[, c("white", "black", "api", "hispanic", "others")],
                   2, weighted.mean, w = FLCensus$total.pop)
race.prop                     # P(race) in Florida overall
total.count <- sum(cnames$count)

# Step 1: P(surname | race) = P(race | surname) P(surname) / P(race)
cnames$name.white    <- (cnames$pctwhite    / 100) * (cnames$count / total.count) / race.prop["white"]
cnames$name.black    <- (cnames$pctblack    / 100) * (cnames$count / total.count) / race.prop["black"]
cnames$name.hispanic <- (cnames$pcthispanic / 100) * (cnames$count / total.count) / race.prop["hispanic"]
cnames$name.asian    <- (cnames$pctapi      / 100) * (cnames$count / total.count) / race.prop["api"]
cnames$name.others   <- (cnames$pctothers   / 100) * (cnames$count / total.count) / race.prop["others"]

# Step 2: attach precinct composition P(race | residence) to each voter
FLVoters <- merge(x = FLVoters, y = FLCensus, by = c("county", "VTD"), all = FALSE)
indx <- match(FLVoters$surname, cnames$surname)

# Step 3: P(surname | residence) = sum over races of P(surname | race) P(race | residence)
FLVoters$name.residence <- cnames$name.white[indx] * FLVoters$white +
    cnames$name.black[indx] * FLVoters$black +
    cnames$name.hispanic[indx] * FLVoters$hispanic +
    cnames$name.asian[indx] * FLVoters$api +
    cnames$name.others[indx] * FLVoters$others

# Step 4: P(race | surname, residence)
FLVoters$pre.white <- cnames$name.white[indx] * FLVoters$white / FLVoters$name.residence
FLVoters$pre.black <- cnames$name.black[indx] * FLVoters$black / FLVoters$name.residence
FLVoters$pre.hispanic <- cnames$name.hispanic[indx] * FLVoters$hispanic / FLVoters$name.residence
FLVoters$pre.asian <- cnames$name.asian[indx] * FLVoters$api / FLVoters$name.residence
FLVoters$pre.others <- 1 - FLVoters$pre.white - FLVoters$pre.black -
    FLVoters$pre.hispanic - FLVoters$pre.asian

# Re-compute the accuracy with the residence information
vars1 <- c("pre.white", "pre.black", "pre.hispanic", "pre.asian", "pre.others")
whites <- subset(FLVoters, subset = (race == "white"))
mean(apply(whites[, vars1], 1, max) == whites$pre.white)
blacks <- subset(FLVoters, subset = (race == "black"))
mean(apply(blacks[, vars1], 1, max) == blacks$pre.black)
hispanics <- subset(FLVoters, subset = (race == "hispanic"))
mean(apply(hispanics[, vars1], 1, max) == hispanics$pre.hispanic)
asians <- subset(FLVoters, subset = (race == "asian"))
mean(apply(asians[, vars1], 1, max) == asians$pre.asian)

# Voters named White: P(black | surname) = 27% nationally. What does residence do?
cnames$pctblack[cnames$surname == "WHITE"]
summary(FLVoters$pre.black[FLVoters$surname == "WHITE"])
Predict: Which group gains most in accuracy when the precinct is added?
Black voters live more segregated than their surnames suggest: the precinct is very informative. Accuracy for them rises from 16% to 63%. Voters named White: the posterior P(black) varies from under 1% to 98% depending on the precinct; that is how strongly the residence moves the prior.
