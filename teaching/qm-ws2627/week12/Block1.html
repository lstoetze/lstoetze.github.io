The lady tasting tea: she claims she can tell whether milk or tea was poured first. 8 cups, 4 of each kind, in random order; she classifies all 8. Null hypothesis \(H_0\): she is guessing.

1. The truth by counting

Under \(H_0\), count the assignments that give 0, 2, 4, 6 or 8 correct cups.

Read this code (it is not run yet):

true <- c(choose(4, 0) * choose(4, 4),     # 0 correct
          choose(4, 1) * choose(4, 3),     # 2 correct
          choose(4, 2) * choose(4, 2),     # 4 correct
          choose(4, 3) * choose(4, 1),     # 6 correct
          choose(4, 4) * choose(4, 0))     # 8 correct
true <- true / sum(true)                   # divide by all 70 assignments
names(true) <- c(0, 2, 4, 6, 8)
true
true["8"]                                 # P(all 8 correct)
true["6"] + true["8"]                     # P(6 or more correct)
Predict: If she is guessing, what is P(all 8 correct)? And P(6 or more correct)?
There are 70 equally likely assignments (8 choose 4). Exactly 1 gives 8 correct (1/70 = 1.4%); 16 give 6 correct: P(6 or more) = 17/70 = 24%. So 6 correct is weak evidence, 8 is strong.

3. Fisher’s exact test

Read this code (it is not run yet):

x <- matrix(c(4, 0, 0, 4), byrow = TRUE, ncol = 2, nrow = 2)   # all 8 correct
y <- matrix(c(3, 1, 1, 3), byrow = TRUE, ncol = 2, nrow = 2)   # 6 correct
rownames(x) <- colnames(x) <- rownames(y) <- colnames(y) <- c("M", "T")
fisher.test(x, alternative = "greater")    # one-sided, 8 correct
fisher.test(y, alternative = "greater")    # one-sided, 6 correct
fisher.test(y)                             # two-sided, 6 correct
Predict: Which result gives a one-sided p-value below 0.05: "all 8 correct" or "6 correct"?
With 6 correct, a guesser would do at least as well 24% of the time: no evidence against H0. With all 8 correct the p-value is 1.4%: reject. The two-sided p-value for 6 correct is 0.49.
