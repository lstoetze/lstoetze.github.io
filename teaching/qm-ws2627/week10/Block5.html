1. The central limit theorem

CLT: the standardized sample mean is approximately N(0, 1), whatever the distribution of the data, if n is large. We repeat 1,000 times: draw 1,000 values, compute the sample mean, standardize it.

Read this code (it is not run yet):

sims <- 1000
n.samp <- 1000
z.binom <- z.unif <- rep(NA, sims)
for (i in 1:sims) {
    x <- rbinom(n.samp, size = 10, prob = 0.2)
    z.binom[i] <- (mean(x) - 2) / sqrt(1.6 / n.samp)            # V = 10*0.2*0.8 = 1.6
    x <- runif(n.samp, min = 0, max = 1)
    z.unif[i] <- (mean(x) - 0.5) / sqrt(1 / (12 * n.samp))      # V = 1/12
}
par(mfrow = c(1, 2))
hist(z.binom, freq = FALSE, nclass = 40, xlim = c(-4, 4), ylim = c(0, 0.6),
     xlab = "z-score", main = "Binomial(10, 0.2)")
lines(x <- seq(-3, 3, by = 0.01), dnorm(x))
hist(z.unif, freq = FALSE, nclass = 40, xlim = c(-4, 4), ylim = c(0, 0.6),
     xlab = "z-score", main = "Uniform(0, 1)")
lines(x, dnorm(x))
Predict: What will the histograms of the z-scores look like, for the (discrete) binomial and the (flat) uniform?
Both histograms follow the standard normal density, although the data themselves are very non-normal. That is the CLT.

2. A probability model for the election

Each state: a poll of n = 1,000 voters, Obama’s true two-party share p. Obama wins the state’s electoral votes (EV) if more than n/2 respondents choose him. Read the loop: what is draws? Why draws > n / 2?

Read this code (it is not run yet):

pres08 <- read.csv("pres08.csv")
pres08$share <- pres08$Obama / (pres08$Obama + pres08$McCain)
n.states <- nrow(pres08)
n <- 1000
sims <- 10000
Obama.ev <- rep(NA, sims)
for (i in 1:sims) {
    draws <- rbinom(n.states, size = n, prob = pres08$share)
    Obama.ev[i] <- sum(pres08$EV[draws > n / 2])
}
hist(Obama.ev, freq = FALSE, main = "Prediction of election outcome",
     xlab = "Obama's electoral college votes")
abline(v = 364, col = "red")             # actual result
summary(Obama.ev)
Predict: Where is the center of the distribution of Obama's electoral votes? Where is the actual result (364)?
The mean is 352; quartiles 340 and 364. The model is sensible: the actual result is a typical outcome. Its standard deviation is about 16 votes.
