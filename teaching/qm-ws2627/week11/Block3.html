A 95% confidence interval is: estimate \(\pm\) 1.96 \(\times\) standard error.

1. Poll: 99%, 95% and 90% intervals

A poll of n = 1,000 finds a sample proportion \(\bar{x} = 0.6\).

Read this code (it is not run yet):

n <- 1000
x.bar <- 0.6                             # an observed sample proportion
s.e. <- sqrt(x.bar * (1 - x.bar) / n)
s.e.
c(x.bar - qnorm(0.995) * s.e., x.bar + qnorm(0.995) * s.e.)   # 99% CI
c(x.bar - qnorm(0.975) * s.e., x.bar + qnorm(0.975) * s.e.)   # 95% CI
c(x.bar - qnorm(0.95)  * s.e., x.bar + qnorm(0.95)  * s.e.)   # 90% CI
Predict: Which interval is widest: 99%, 95% or 90%? Which one would you bet on?
The s.e. is 0.0155; the 99% interval is 0.560 to 0.640, the 95% interval 0.570 to 0.630, the 90% interval 0.575 to 0.625. Higher confidence costs precision.

2. Coverage: how often does the 95% interval contain the truth?

Read the simulation: p is the true proportion (0.6), ci.results records whether each interval contained it.

Read this code (it is not run yet):

set.seed(2026)
p     <- 0.6
alpha <- 0.05
sims  <- 5000
n.vec <- c(10, 50, 100, 1000)
results <- rep(NA, length(n.vec))
for (i in 1:length(n.vec)) {
    ci.results <- rep(NA, sims)
    for (j in 1:sims) {
        data  <- rbinom(n.vec[i], size = 1, prob = p)      # simple random sample
        x.bar <- mean(data)
        s.e.  <- sqrt(x.bar * (1 - x.bar) / n.vec[i])
        ci.lower <- x.bar - qnorm(1 - alpha / 2) * s.e.
        ci.upper <- x.bar + qnorm(1 - alpha / 2) * s.e.
        ci.results[j] <- (p >= ci.lower) & (p <= ci.upper)
    }
    results[i] <- mean(ci.results)
}
names(results) <- n.vec
results
Predict: Is the coverage of the "95%" interval exactly 95%? For which sample size is it furthest away?
Coverage is 0.90, 0.94, 0.94 and 0.95 for n = 10, 50, 100, 1000. The normal approximation needs enough data: with n = 10 the interval is too narrow.
