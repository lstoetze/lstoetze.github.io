1. Difference in means with a confidence interval

The resume experiment from Week 3: callback rates for white vs. black names.

Read this code (it is not run yet):

resume <- read.csv("resume.csv")
n1 <- sum(resume$race == "white");  n0 <- sum(resume$race == "black")
p1 <- mean(resume$call[resume$race == "white"])
p0 <- mean(resume$call[resume$race == "black"])
est <- p1 - p0                                    # difference in callback rates
se  <- sqrt(p1 * (1 - p1) / n1 + p0 * (1 - p0) / n0)
c(n1 = n1, n0 = n0, p1 = p1, p0 = p0, est = est, se = se)
ci  <- c(est - qnorm(0.975) * se, est + qnorm(0.975) * se)
ci                                                # does it contain 0?
Predict: Compute the difference in callback rates and a 95% CI. Does the interval contain 0?
Difference 3.2 points, s.e. 0.78 points, 95% CI [1.7, 4.7]. Zero is outside: the difference is unlikely to be due to chance alone.

2. How large a sample do you need?

Sample size for a margin of error (MoE): \(n = 1.96^2\, p(1-p) / \text{MoE}^2\).

Read this code (it is not run yet):

MoE <- c(0.01, 0.03, 0.05)
p <- seq(from = 0.01, to = 0.99, by = 0.01)
n <- 1.96^2 * p * (1 - p) / MoE[1]^2
plot(p, n, ylim = c(0, 11000), type = "l", xlab = "Population proportion", ylab = "Sample size")
lines(p, 1.96^2 * p * (1 - p) / MoE[2]^2, lty = "dashed")
lines(p, 1.96^2 * p * (1 - p) / MoE[3]^2, lty = "dotted")
# n for p = 0.5 and each MoE (the worst case):
1.96^2 * 0.5 * 0.5 / MoE^2
Predict: Looking at the worst case p = 0.5: roughly what sample size gives a margin of error of 3 percentage points?
n = 1.96² × 0.25 / 0.03² = 1,067. For ±1 point you need 9,604; for ±5 points only 384. Halving the margin of error costs four times as many respondents.
