The standard error is the standard deviation of the sampling distribution of the estimator.

1. The sampling distribution

Read this code (it is not run yet):

set.seed(2026)
n <- 100
PATE <- 1
sims <- 5000
diff.means <- se <- rep(NA, sims)
for (i in 1:sims) {
    Y0 <- rnorm(n, mean = 0, sd = 1)
    Y1 <- rnorm(n, mean = 1, sd = 1)
    treat <- sample(c(rep(1, n / 2), rep(0, n / 2)), size = n, replace = FALSE)
    diff.means[i] <- mean(Y1[treat == 1]) - mean(Y0[treat == 0])
    se[i] <- sqrt(var(Y1[treat == 1]) / (n / 2) + var(Y0[treat == 0]) / (n / 2))
}
hist(diff.means, freq = FALSE, xlab = "Difference-in-means estimator",
     main = "Sampling distribution")
abline(v = PATE, col = "red")
sd(diff.means)                           # the "truth"
mean(se)                                 # average ESTIMATED standard error
Predict: Compare the true standard error (sd(diff.means), from simulation) with the average estimated standard error computed from each sample.
sd(diff.means) = 0.198, mean estimated s.e. = 0.199. We can estimate the standard error from one sample: sqrt(V1/n1 + V0/n0). That is what lets us quantify uncertainty with a single dataset.

2. Consistency: the standard error shrinks like \(1/\sqrt{n}\)

Read this code (it is not run yet):

for (m in c(25, 100, 400, 1600)) {
    est <- replicate(2000, mean(rnorm(m, mean = 1, sd = 1)))
    cat("n =", m, " sd of the sample mean =", round(sd(est), 3),
        " theory 1/sqrt(n) =", round(1 / sqrt(m), 3), "\n")
}
Predict: By what factor does the standard error of the sample mean shrink when n is multiplied by 4?
For n = 25, 100, 400, 1600 the s.e. is 0.20, 0.10, 0.05, 0.025: each time n is multiplied by 4, the s.e. halves. To halve your uncertainty you need four times as much data.
